# Galgame 可视化编辑器 · 桌面版

Windows 桌面版 Galgame 多轨可视化编辑器。用时间轴编排台词、背景、立绘、音乐和配音，在编辑器里预览演出，再导出成 [WebGAL](https://github.com/OpenWebGAL/WebGAL) 工程或带签名的游戏 exe。

本仓库是桌面发行包，内含可直接运行的 `galgame-editor.exe`、使用说明、自签名证书和演示用 Live2D 模型。不含编辑器源码。

## 能做什么

编辑器把一章演出摊在时间轴上，按轨道摆片段：

- 台词、背景、图片、立绘
- 背景音乐、音效、配音
- 特效，以及故事线说明

立绘可以是静态图，也可以挂模型：

- **Live2D**：导入 Cubism 导出的整个模型目录（`.model3.json`、`.moc3`、纹理）。编辑器内可预览模型并播放动作与表情。
- **Spine**：按目录导入，导出时写成 WebGAL 的 `changeFigure`（带 `?type=spine`），动作和皮肤可写入脚本。
- **DragonBones**：导入 `*_ske.json`、`*_tex.json`、`*_tex.png`，也支持 `*_ske.dbbin`。编辑器内可预览骨骼动画。官方 WebGAL 播放器目前没有这条通道，导出后要在播放器侧自行接入，或改成序列帧再使用。
- **序列帧 / 动图**：GIF、WebM 可直接预览；PNG 序列可在编辑器里逐帧看，导出时烘焙成 GIF。

其他常用能力：

- 素材库按文件夹管理。搜索支持拼音首字母，例如输入 `smsn` 找「神秘少女」。
- 图片立绘可配置口型与眨眼差分。导出到 WebGAL 后，由引擎按配音音量切换嘴型。
- 分支、变量、章节调用会尽量按 WebGAL 方言来回转换。
- 从官方脚本导入时，`callScene`（播完回到调用点）和 `changeScene`（跳走不返回）会拆成独立章节，并标出调用关系。
- 可将成品导出为 Windows 游戏 exe，并自动做数字签名。

编辑器不做绑骨、权重、IK。模型请用 Live2D Cubism Editor、Spine 或 DragonBones Pro 制作，再把导出的目录放进素材库。

## 运行

1. 解压整个压缩包。`演示模型` 和 `证书` 要和 exe 留在同一层，不要只把 exe 单独拷走。
2. 双击 `galgame-editor.exe`。
3. 看标题栏。正确的构建号是 `Galgame可视化编辑器 · R233 (11-06)`。如果还是更旧的号码，说明打开的是以前解压的包。

第一次在没装过证书的电脑上运行，Windows 可能弹出「Windows 已保护你的电脑」。点「更多信息」，再点「仍要运行」。程序可以正常使用。这是自签名，不是文件损坏。细节见 `证书/自签名说明.txt`。

## 第一次使用

1. 启动后在开始界面选择「新建工程」，或「加载演示模板」先看一条现成的多章演出。
2. 菜单「文件 → 指定素材库文件夹」，选一个用来存放立绘、背景、音频和模型的目录。模型相关按钮在指定素材库之前不可用。
3. 把素材放进素材库。音频支持 MP3、WAV、OGG、M4A、AAC、FLAC、OPUS、WEBM、AIFF。没有真实文件的内置占位音频会保持静音，不会报错。
4. 在时间轴上加片段，拖动调整起止，在右侧属性面板改台词、动作、帧率等。
5. 需要预览 Live2D 时：顶栏打开「模型」，选择「导入演示模型 eyu」。模型来自同级目录 `演示模型/eyu/`，不用再自己找文件夹。导入后，把立绘片段的类型改成 Live2D，播放头走到该片段即可看到模型。

应用内「使用说明」有布局、时间轴和导出的图解，可离线打开。

## 和 WebGAL 对接

- **导出**：菜单「文件 → 导出 WebGAL」。得到 `start.txt` 和各章 `chapter_*.txt`，模型目录会拷进工程的 `game/figure/`。
- **导入**：菜单「文件 → 导入 WebGAL」。可读回官方工程里的条件分支、变量、粒子、滤镜运镜、章节跳转、模型与口型。

有些效果在编辑器里能摆，但官方脚本没有对应写法。导出时会保留成以 `;` 开头的注释，不会把这段内容丢掉。目前包括：图片轨上的视频、聚光、震动、跟随、负片、萤火虫、星光，以及选项的显示条件。

Live2D 在 WebGAL 工程里播放时，需要自行准备 Cubism 运行时并放入工程。Spine、DragonBones 也要按各自运行时的要求在播放器侧配置。编辑器里的预览不依赖这些运行时。

## 导出游戏 exe

导出流程结束时，编辑器会给成品 `<游戏名>.exe` 写入数字签名。未单独设置作者时，签名者是 Galgame Visual Editor。

菜单「文件 → CA签名（游戏作者信息）」里可以填写作者名和组织。之后导出的游戏证书主体会带上这些名字，并固定包含 `OU=Made with Galgame Visual Editor`。证书和私钥只在本机使用，不会上传。

玩家的电脑如果没安装 `证书/galgame-selfsigned.cer`，第一次打开游戏 exe 时仍可能看到 SmartScreen。处理方式和打开编辑器相同。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 双击没有反应或马上退出 | 右键「以管理员身份运行」。若有报错窗口，把标题栏构建号和截图一起留下 |
| SmartScreen 拦截 | 「更多信息」→「仍要运行」 |
| 时间轴内容挤在一起 | 用时间轴工具栏的密度按钮切到「完整」，或把时间轴拉宽 |
| 模型按钮是灰的 | 先执行「文件 → 指定素材库文件夹」。模型功能只在桌面版提供 |
| 导出到 WebGAL 后少了效果 | 打开导出的脚本，看以 `;` 开头的注释。那些是当前没有对应写法、被原样留下的部分 |
| 占位音乐没有声音 | 预期行为。到素材库导入真实音频后再播放 |

反馈时请带上标题栏里的构建号、复现步骤，以及截图或工程文件。
